Townlight / Townlight Planning

Cited planning policy support that keeps humans responsible.

Townlight Planning is the comprehensive-plan policy lookup and cited planning analysis support module for Townlight.

v0.2.2 corrective demotion state

Current State

The previous v1.0.0 release was published in error. Townlight Planning v0.2.2 is a narrow truth-repair release with no functional upgrade. It exists solely to supersede the false v1.0.0 release from 2026-05-21 in GitHub's Latest impression; the Townlight Core pin is unchanged. The FastAPI service, cited plan-policy lookup, staff-only local policy ingestion via CIVICPLAN_POLICY_DB_URL, goal/objective/policy navigator, cited plan Q&A, cross-plan synthesis, amendment history, progress tracking, Townlight Zoning and Townlight Meetings context contracts, consistency support, staff-analysis outline, records-ready export checklist, local adversarial integration mocks, and public UI exist. Townlight Planning does not make official planning determinations, provide legal advice, call live external systems by default, or replace planner/elected-body judgment.

Product Promise

  • Find adopted plan-policy context with citations.
  • Return cited, review-required plan-policy context for Townlight Zoning zoning questions.
  • Surface sample consistency factors for staff review.
  • Draft cited staff-analysis outlines without making official determinations.
  • Preserve source/proposal/reviewer provenance for municipal records.
